# Getting started

Two short pages to get you from nothing to a packet on the wire.

<div class="grid cards" markdown>

-   :material-download: **[Installation](installation.md)**

    ---

    Build from source with CMake (recommended) or autotools, or install from
    your OS package manager. Includes the optional fast-path backends.

-   :material-rocket-launch: **[Quickstart](quickstart.md)**

    ---

    Replay a shipped sample capture, watch the statistics, then rewrite and
    replay it — the whole loop in about five minutes.

</div>

!!! tip "Just want the commands?"
    If you already have a build, jump straight to the
    [Quickstart](quickstart.md). If you want the exhaustive option list for any
    tool, the [man pages](../reference/man-pages.md) are the authority; these
    guides focus on *how to use* the tools.
